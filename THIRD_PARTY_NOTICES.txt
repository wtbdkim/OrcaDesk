ORCAdesk 0.11.3 for Windows: third-party notices
================================================

This file lists the software that ships in the Windows build of ORCAdesk:
the installer, and the program folder it installs (the same folder build.bat
makes in dist\ORCAdesk). For each component it gives the version, the
license, the copyright notice, the files it occupies (relative to the program
folder) and the file in the licenses folder that holds the full license text.

Why the build as a whole is conveyed under the GNU GPL v3, and where the
corresponding source is: see LICENSE-BINARY.txt.

The list was made from the files actually present in dist\ORCAdesk after a
build from the clean environment pinned in requirements-build.txt (CPython
3.12.10, PyInstaller 6.20.0). Where each license text comes from is listed
at the end.
