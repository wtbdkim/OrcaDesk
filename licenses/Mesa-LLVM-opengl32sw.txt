opengl32sw.dll: Mesa 3D llvmpipe (software OpenGL renderer)
=============================================================

_internal\PyQt6\Qt6\bin\opengl32sw.dll ships in the PyQt6-Qt6 wheel. Qt loads it
only when no usable OpenGL driver is present (for example in a virtual machine
or a remote session). It is a build of Mesa 11.2.2's llvmpipe driver, which
contains LLVM 3.6.2 (both versions read from the strings in the binary).

Sources of the texts below:
  - Mesa: docs/license.html at tag mesa-11.2.2,
    https://gitlab.freedesktop.org/mesa/mesa/-/raw/mesa-11.2.2/docs/license.html
    (HTML converted to plain text)
  - LLVM: llvm/LICENSE.TXT at tag llvmorg-3.6.2,
    https://raw.githubusercontent.com/llvm/llvm-project/llvmorg-3.6.2/llvm/LICENSE.TXT
